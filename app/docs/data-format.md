# TWIN 자료 형식과 실제 자료 연결 방법

현재 함께 제공하는 예제는 **실제 댐과 무관한 합성자료**입니다. 모델의 실제 예측 정확도, 실제 발전량 증가 또는 수질 개선의 근거로 사용하면 안 됩니다. 프로그램에서 입력, 계산, 화면, 내보내기를 확인하는 용도입니다.

## 파일 구조

CSV는 첫 행을 열 이름으로 쓰고, 이후 한 행에 한 시각의 자료를 넣습니다. UTF-8로 저장하세요. Excel은 사용할 시트와 열을 선택합니다. 단위는 열 이름만 보고 확정하지 않으므로 업로드 화면에서 반드시 확인하세요. 원본 자료는 별도로 보존합니다.

Excel 숫자는 화면에 표시된 반올림 값이 아니라 저장된 원래 값을 읽습니다. Excel 날짜 형식의 셀은 통합문서의 날짜 시스템을 적용해 시각으로 변환하므로 날짜만 표시되는 셀도 내부에 시간 정보가 있으면 보존합니다. 숫자 일련번호를 `일반` 형식으로 저장한 경우에는 날짜인지 판별할 수 없으므로 Excel에서 날짜 형식으로 바꾸거나 ISO 문자열로 정리하세요. 3행 미만의 설명 시트는 건너뜁니다. 수식을 재계산하지 않고 파일에 저장된 계산 결과를 읽으므로 Excel에서 재계산과 저장한 후 불러오세요. 저장된 결과가 없으면 결측값으로 검사합니다.

| 내부 열 이름 | 내용 | 기본 단위 | 필수 여부 |
|---|---|---|---|
| `timestamp` | 구간 시작 시각 | ISO 8601 또는 `YYYY-MM-DD HH:mm` | 필수 |
| `inflowCms` | 해당 구간의 평균 유입유량 | m³/s | 필수 |
| `observedReleaseCms` | 해당 구간의 평균 총방류유량 | m³/s | 선택 |
| `observedTurbineCms` | 해당 구간의 평균 발전방류유량 | m³/s | 선택 |
| `observedStorageMcm` | 구간 시작 시점의 저수량 | 백만 m³ | 선택 |
| `observedLevelM` | 구간 시작 시점의 저수위 | m | 선택 |
| `observedGenerationMWh` | 해당 구간 동안 생산한 전기에너지 | MWh | 선택 |
| `observedTurbidityNtu` | 측정 위치가 확인된 탁도 | NTU | 선택 |

한글 열 이름도 직접 연결할 수 있습니다. 자동 연결은 편의를 위한 제안이므로 원본 설명서와 대조하세요. 예를 들어 발전방류량을 총방류량으로 연결하면 수지 계산이 달라집니다. 데이터 정리 후 전체를 다시 검증해야 합니다.

### 시각과 시간 간격

- 시간대가 없는 문자열은 기본적으로 한국시간 `+09:00`로 해석합니다. 데이터가 UTC이면 업로드 시 시간대를 바꾸거나 각 시각에 `Z`를 붙이세요.
- `2026-07-01 00:00`와 `2026-06-30T15:00:00Z`는 같은 시각입니다. 이런 중복도 거부합니다.
- 내부에서는 UTC ISO 문자열로 보존합니다. 표시 시간대와 내부 문자열의 차이를 자료 오류로 오인하지 마세요.
- 최소 2행이 필요하고 모든 행의 시간 간격이 일정해야 합니다. 시간 순서가 뒤섞였으면 알림 후 정렬하지만, 중복이나 누락 구간은 자동으로 합치거나 보간하지 않습니다.
- 모든 행은 **그 시각에 시작하는 구간**을 뜻합니다. 예를 들어 00:00행의 시간당 발전량은 00:00부터 01:00까지의 발전량입니다. 마지막 행도 한 구간을 나타냅니다.
- 기관 자료가 구간 종료 시각으로 기록되어 있으면 시간 간격만큼 시각을 먼저 옮기고, 처리 내용을 별도 기록하세요.
- 유입과 방류량이 순간 측정값인지 구간 평균인지 제공기관에 확인하세요. 순간값을 그대로 긴 구간 평균으로 간주하면 물수지 오차가 커질 수 있습니다.

### 단위 변환

| 항목 | 선택 가능한 입력 단위 | 프로그램의 내부 변환 |
|---|---|---|
| 유입, 총방류, 발전방류 | m³/s 또는 m³/day | m³/day ÷ 86,400 → m³/s |
| 저수량 | 백만 m³(MCM) 또는 m³ | m³ ÷ 1,000,000 → MCM |
| 구간 발전량 | MWh 또는 kWh | kWh ÷ 1,000 → MWh |
| 저수위, 탁도 | m, NTU | 변환 없이 사용 |

`m³/day`는 유량의 표현 단위입니다. 여러 시간에 걸쳐 누적한 물의 양(m³)을 곧바로 m³/day로 선택하면 안 됩니다. 먼저 누적량의 차이를 시간으로 나누어 유량을 구하세요.

발전량은 **구간 에너지**입니다. 순간 전력(MW), 하루 누계 또는 전체 누적 계량값은 자동 변환하지 않습니다. 발전기 1, 2호기 등 여러 열이 있으면 같은 기간, 단위인지 확인한 후 합계 열을 만들어 연결하세요. 발전량을 자동으로 발전방류량으로 환산하지도 않습니다.

### 결측과 잘못된 자료

- 필수인 시각과 유입량이 없으면 불러오기를 중단합니다.
- 선택 항목의 빈칸은 `null`로 유지합니다. `0`은 실제 0을 뜻하므로 결측을 0으로 채우지 마세요.
- 빈칸, `-`, `—`, `NA`, `N/A`, `null`, `NaN`, `결측`은 결측 표기로 읽습니다.
- 다른 문자가 섞인 숫자, 음수 유량, 저수량, 발전량, 탁도, 발전방류량이 총방류량을 초과하는 행은 거부합니다. 저수위는 기준면에 따라 음수가 가능하므로 숫자 여부만 검사합니다.
- 일부 행에 오류가 있으면 전체 자료를 적용하지 않습니다. 정상 행만 조용히 빼서 사용하지 않습니다.
- 최대 20,000행이며 CSV 문자열은 20MB 이하입니다. 더 긴 원자료는 연구 기간별로 잘라 사용하세요.

## 실제 자료를 받으면 할 일

1. 원본 파일과 제공기관 설명서를 보존하고, 출처, 제공일, 기간, 단위, 측정 위치, 결측 표기, 시각 기준을 기록합니다.
2. 하나의 댐 또는 관측소와 일정한 시간 간격을 선택합니다. 여러 장소를 같은 시계열에 섞지 않습니다.
3. 시각 기준을 맞추고, 필요한 경우 발전기별 구간 발전량을 합산합니다. 모든 변환 과정을 기록합니다.
4. 파일을 불러와 열과 단위를 연결합니다. 자료 종류는 실제 관측자료인지 직접 확인한 뒤 지정합니다.
5. 기관 자료와 별도로 댐의 용량, 초기 저수량, 수위 관계, 방류 한계, 발전 효율 등 시설 설정을 입력합니다. **파일을 넣는 것만으로 가상 댐 설정이 실제 댐 설정으로 바뀌지는 않습니다.**
6. 실제 총방류량을 사용한 재현 계산부터 관측 저수량과 대조하고, 불일치 원인과 자료 누락을 확인합니다. 같은 자료로 보정과 검증을 모두 끝내지 않습니다.
7. 검증에 쓰지 않은 기간을 남겨 비교합니다. 합성 예제나 모델 자체가 만든 정답과 잘 맞는다고 실제 성능이 검증되는 것은 아닙니다.

탁도는 이 형식에서 관측값을 보존하는 선택 열입니다. 한 지점의 탁도 열만으로 깊이별 수질, 선택취수, 하류 도달시간, 정수 약품 절감 효과를 계산할 수는 없습니다. 해당 자료와 별도 검증 모델을 확보한 뒤 확장하세요.

## 예제 파일

- `samples/SYNTHETIC_합성예제_168시간.csv`: 168시간짜리 가상 댐 예제. 자료 종류는 합성으로 지정합니다.
- `samples/input_template.csv`: 표준 열 이름만 있는 빈 양식. 실제 자료를 채우기 전에는 실행할 수 없습니다.
- `samples/SYNTHETIC_합성예제_단위변환.csv`: 첫 24시간을 m³/day와 m³, kWh로 바꾼 업로드 연습용 파일. 단위를 올바르게 선택해야 합니다.
- `samples/SYNTHETIC_합성예제_설명.json`: 예제의 합성 여부와 생성 목적을 보존한 메타데이터.
- `samples/TWIN_SYNTHETIC_Excel예제.xlsx`: 같은 168시간 자료를 담은 Excel 예제. 설명 시트를 건너뛰고 자료 시트를 읽는지, 원래 숫자 정밀도와 시각이 보존되는지 확인할 수 있습니다.

화면에서 내보낸 입력 CSV에는 sourceKind, source, configStatus 열이 포함됩니다. sourceKind 또는 dataOrigin 열에 synthetic 표시가 있으면 재업로드 때 합성자료 구분을 유지합니다. 일반 기관 CSV나 예전 예제처럼 표시가 없는 파일은 자료 구분과 출처를 직접 지정해야 합니다. 전체 변환 설정은 프로젝트 JSON에 보관하세요. 파일명과 원본 설명 파일도 함께 보존합니다.
