# AI 예측 안내 (1.6)

작성일 2026-10-19. 프로그램의 ‘AI 예측’ 화면과 운영 실험실의 AI 관련 표시가 무엇을 계산하고 무엇을 계산하지 않는지 설명한다. 학습과 평가 절차의 전체 기록은 AI 폴더의 `README_AI_만드는법.md` 10절에 있다.

## 1. 모형

| 항목 | 내용 |
|---|---|
| 하는 일 | 발행 시각 t까지의 유입량 기록만 보고 1시간부터 24시간 뒤까지의 유입량 24개를 한 번에 예측한다 |
| 입력 | 직전 48시간의 유입량. 각 시각은 표준화한 log1p(유입량)과 시각(hour)의 sin, cos 세 채널이다. 표준화 통계는 학습 구간에서만 구한다 |
| 출력 | log1p 공간의 변화량 d_h (−4~4로 제한). 예측값은 expm1(log1p(q_t) + d_h)를 0 이상으로 제한한 값 |
| 구조 | 6월 설정 선택에서 이긴 구조 하나. 후보는 LSTM(은닉 32/64, 1/2층)과 Transformer 인코더(d_model 32/64, 1/2층, 4헤드, 학습 위치부호, 마지막 토큰의 LayerNorm) |
| 학습 | 2024년 1~5월 표본으로 학습하고 6월 h=3 MAE로 설정과 에폭을 고른 뒤, 7월 1일 00:00까지 목표가 공개된 표본으로 가중치만 다시 학습한 것(시드 0)을 프로그램에 넣었다 |
| 실행 | `src/ai-forecast.mjs`가 가중치 JSON을 읽어 브라우저 JavaScript로 같은 계산을 한다. PyTorch가 저장한 검증 벡터 64개와 비교하는 자동 시험(`tests/ai-forecast.test.mjs`)이 있다 |
| 제한 | 공개 유입량 한 해로만 학습했고 강우나 상류 관측을 쓰지 않는다. 유입량이 저수량과 방류로 산정된 값이라는 자료의 성격도 그대로 물려받는다 |

프로그램의 예측은 발행 시각 뒤 24개 구간의 유입량이며, 발행 시각은 현재 자료의 각 구간 끝이다. 자료가 1시간 간격이 아니면 예측을 만들지 않는다(화면에 이유가 표시된다). 처음 48개 구간은 창을 채울 기록이 없어 예측이 없다.

## 2. 화면의 각 요소가 뜻하는 것

| 요소 | 계산 | 주의 |
|---|---|---|
| 예측과 실측 그래프 | 지평 h의 예측값을 목표 시각 위치에 그린다. 유지 기준선은 h시간 전의 실측값 | 예측을 발행 시각에 그리면 실제보다 좋아 보인다. 이 프로그램은 목표 시각에 그린다 |
| 예측 오차 그래프 | 예측 − 실측 | 양수는 과대예측, 음수는 과소예측 |
| 선택 구간의 24시간 예측 | 선택 구간 끝에 발행된 24개 값. 띠는 2024년 6월 검증 잔차의 10~90% 분위수를 더한 경험적 범위 | 보정된 예측구간이 아니다. 학습 범위를 넘는 홍수에서는 실제 오차가 띠보다 훨씬 클 수 있다 |
| 지평별 MAE | 현재 자료에서 실측이 있는 발행 시각 전부의 평균 절대오차 | 가상 자료나 2024년 7월 이전 자료는 성능 근거가 아니다 |
| 2024년 소양강댐 평가 | 7~9월 주평가(매월 1일 재학습)의 고정 결과. 아래 3절 | 프로그램을 다시 실행해도 바뀌지 않는다 |
| 현재 구간 표의 AI 예측 유입 | 직전 구간 끝에 발행된 예측의 지평 평균(예측 참고 지평, 기본 6시간) | 예측이 없으면 ‘없음’ |
| 3D 예상 수위 표시면과 라벨, 수위 그래프의 AI 예측 궤적 | 예측 유입량 24개를 현재 저수량에서 목표 저수량 유지 규칙으로 돌린 물수지 계산 | AI가 수위를 예측한 것이 아니다. 목표 저수량 설정을 바꾸면 달라진다 |
| AI 예측 참고 규칙 (제안 운영안) | 목표 저수량 유지 규칙에서 다음 구간 유입량 가정을 현재 값 대신 예측 지평 평균으로 바꾼 것 | 최적화(MPC)나 강화학습이 아니다. 예측이 없는 구간은 현재 값을 쓴다 |

## 3. 2024년 소양강댐 평가 결과

6월 설정 선택에서 LSTM(은닉 64, 1층, 10에폭, 6월 h=3 MAE 20.44)이 Transformer(d_model 64, 1층, 24에폭, 21.42)를 앞서 프로그램에 들어갔다. 2024년 소양강댐 7~9월 주평가(3시간 앞, 2,190개 발행 시각)에서 LSTM의 MAE는 44.3 m³/s로 Ridge 47.7, 유지 기준선 53.4보다 낮았고, 짝지은 절대오차 차이의 블록 부트스트랩 95% 범위(LSTM − Ridge −3.40, [−5.95, −1.31]과 [−5.93, −1.86])가 0을 포함하지 않았다. Transformer(49.5)는 Ridge와의 차이 근거가 부족했다. 다만 고유입 구간(실측 122.4 m³/s 이상, 791개)에서 LSTM의 평균 과소예측 67.4 m³/s는 유지 기준선 51.2보다 커서 홍수 대응 성능이 좋아졌다고는 말하지 않는다. 지평별로는 1, 3, 6, 12, 24시간 모두 LSTM이 가장 낮은 MAE였고(1시간 46.3, 6시간 55.2, 12시간 68.2, 24시간 83.6), 10~12월 보조평가에서도 LSTM 27.3, Transformer 28.9, Ridge 30.7, HGB 29.5, 유지 36.9였다. 상태 채널(총방류, 저수위, 저수량)을 더한 변형은 기본 채널보다 나빴다(LSTM 48.1, Transformer 52.3). 2024년 7월 18일 19시의 최대 유입 2,138 m³/s에 대해 16시에 발행된 3시간 예측은 LSTM 851, Transformer 926 m³/s로 둘 다 크게 과소예측했다. 아래 표는 `assets/ai/evaluation.json`과 AI 폴더 `결과/40~42` 파일의 숫자다.

## 5. 다시 만들거나 바꾸려면

AI 폴더에서 `python3 code/06_deep_models.py <원문23열.csv> 결과`를 실행하면 40~43번 결과 파일과 `예측기록/predictions_deep_base.csv`가 생긴다(2 CPU 기준 약 1시간 20분). `python3 code/07_export_app.py 결과 <프로그램>/assets/ai`가 `model.json`과 `evaluation.json`을 만든다. 7월 결과를 본 뒤 설정을 바꾸는 것은 사후 조정이므로, 바꾸려면 다른 연도나 기간에서 새로 평가해야 한다.
