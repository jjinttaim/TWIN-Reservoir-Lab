# 수로와 정보 보기 (TWIN 1.3)

1. 운영 실험실에서 **방류 많은 시점**을 선택합니다. 현재 제안 운영안의 최대 총방류 구간으로 이동합니다.
2. **전체화면**, **하류 쪽** 또는 **여수로**를 선택해 물길을 봅니다.
3. 장면 안 시설 라벨이나 정보 패널의 **저수지, 발전소, 여수로, 하류**를 누릅니다. 선택 시설의 숫자와 설명이 맨 위에 나옵니다.
4. 아래 **3D 재생 막대**로 시간을 옮기거나 이전과 다음 구간을 비교합니다. 패널 수치와 물 흐름이 함께 바뀝니다.
5. **모형 가정과 수로 수치**를 열면 표시 수로의 근사 수심, 평균 유속, 해석 범위를 볼 수 있습니다. **자료 출처와 숫자 구분**에서 입력과 계산의 차이를 확인합니다.
6. **화면 PNG 저장**으로 장면과 현재 구간 정보를 함께 저장합니다. 전체 계산 결과는 별도의 결과 CSV, 재현할 조건은 프로젝트 JSON으로 저장합니다.

## 숫자 읽는 법

| 표시 | 뜻 |
| --- | --- |
| 유입, 총방류, 발전용, 비발전 방류 m³/s | 선택 구간의 평균 유량 |
| 저수량 변화 백만 m³ | 그 구간의 끝 저수량 − 시작 저수량 |
| 계산 수위와 저수량 | 구간 끝 값 |
| 자료 속 수위와 저수량 | 자료 시각, 즉 구간 시작의 입력값 |
| 발전량 MWh | 선택 구간에 계산된 에너지 |
| 평균 출력 MW | 그 구간의 평균 발전 속도 |
| 입력자료 | 선택한 원자료의 값. 가상 자료이면 관측값이 아님 |
| 계산값 | 선택한 운영안과 제원으로 계산한 값 |
| 모형가정 | 실측으로 보정하지 않은 수로 근사 |
| 미제공 | 원자료에 해당 값이 없음. 0과 다름 |

발전용 + 비발전 방류 = 총방류입니다. 여수로 아래부터 발전 방류 합류 전까지는 비발전 방류만, 합류 후에는 두 유량의 합을 표시합니다. 비발전 방류에는 물수지 모형에서 용량을 넘겨 흘린 양도 포함됩니다. 이를 실제 특정 수문에서 관측한 유량으로 읽으면 안 됩니다.

## 표현과 해석의 범위

수로의 하상, 둑, 주변 지면을 연결하고 주변 계곡과 같은 PBR 질감을 적용했으며, 물의 반복적인 흰 무늬를 줄였습니다. 물결은 중심선 방향을 따라 이동하며 화면 시간으로 움직입니다. 자료 재생의 한 구간은 예제에서 1시간이지만, 물결 자체를 1시간씩 빨리 감는 방식은 아닙니다.

수로 수심과 평균 유속은 가정한 단면, 폭, 경사, 거칠기를 사용하는 정상등류 근사입니다. 합류, 여수로 말단의 수면 연결과 거품은 시각 표현이고, 난류, 도수, 홍수 도달 시간을 해석하지 않습니다. 주변 지형도 측량 자료가 아닙니다. 실제 자료를 넣어도 외형과 수리 매개변수가 자동 보정되지는 않습니다.

날씨 선택은 화면의 비, 바람, 안개를 바꿉니다. 입력 유입량과 물수지는 그대로입니다. 물결 움직임을 꺼도 선택 시각의 계산 결과는 바뀌지 않습니다.
