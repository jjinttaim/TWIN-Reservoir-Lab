# 소양강댐 외형 참고 3D 장면 (TWIN 1.5)

## 장면의 의미

이 장면은 소양강댐을 연상할 수 있는 외형과 주변 풍경을 사용하는 연구 프로그램의 표시 화면입니다. 측량, 설계 도면에서 재구성한 정밀 구조 모델이나 공식 시설 모델이 아닙니다. 지형의 작은 굴곡, 식생, 도로, 건물 배치는 화면 구성을 위한 근사 표현일 수 있습니다. 수치 계산의 기본 제원과 168시간 입력자료도 가상입니다.

실제 자료를 불러와도 외형이 자동으로 실측 모델이 되지는 않습니다. 프로그램에서 자료 출처와 제원을 확인하고 별도 검증해야 합니다.

## 실행

`시작.command`를 실행하고 표시되는 127.0.0.1 주소로 접속합니다. GLB와 장면 JSON을 읽으므로 `index.html` 직접 실행 대신 로컬 HTTP 서버를 사용합니다. Blender는 모델 편집에만 필요하며 브라우저에서 감상하거나 자료를 연결할 때는 필요하지 않습니다.

높은 화질이 기본입니다. GPU 성능이나 화면 크기에 따라 느리면 일반 화질을 선택합니다. 브라우저의 WebGL이 비활성화되면 계산과 자료 화면은 사용할 수 있어도 3D는 표시되지 않을 수 있습니다. 모델 로딩 오류가 표시되면 원래 폴더 구조와 서버 실행 상태를 확인하세요.

## 카메라와 재생

전체 풍경, 호수 쪽, 여수로 입구, 호숫가, 전망광장, 여수로, 감세지, 발전소, 하류 쪽, 위에서의 열 시점이 있으며 3D 장면 제목 오른쪽의 시점 목록에서 고릅니다. 전망광장은 1.4에서 추가한 우안 광장에서 댐마루와 여수로를 보는 시점이고, 감세지와 발전소는 1.5에서 추가한 플립 버킷 아래 감세지와 2기 발전소를 보는 시점입니다. 마우스로 회전, 확대, 이동할 수 있고 자동 둘러보기는 카메라를 천천히 움직입니다. 물결 움직임과 자료 재생은 서로 독립적입니다. 자료 재생은 시간별 계산 상태를 선택하고, 물결 움직임은 그 상태를 그리는 시각효과만 바꿉니다.

**방류 많은 시점**은 현재 제안 운영안의 계산 결과에서 총방류량이 가장 큰 구간으로 이동하고 재생을 멈춥니다. 입력자료, 제원, 운영안은 바꾸지 않으며 카메라도 유지합니다.

재생마다 3D 화면을 새로 만들지 않으므로 카메라와 전체화면이 유지됩니다. 다른 메뉴로 이동하면 GPU 리소스를 정리하고 돌아올 때 뷰어를 다시 생성합니다. 시설 라벨 또는 정보 패널의 저수지, 발전소, 여수로, 하류를 누르면 현재 구간의 해당 시설 정보가 표시됩니다. 전체화면에서도 별도 시간 막대를 사용할 수 있습니다. 화면 PNG 저장은 현재 3D 카메라 화면과 선택 시설의 숫자를 출처 주석과 함께 내보내며, 계산 재현에는 별도로 프로젝트 JSON이 필요합니다.

모델은 다음 경로 구조로 연결합니다. `.blend`와 미리보기는 편집과 검토용이고 브라우저의 실행 입력은 GLB와 장면 JSON입니다.

## 물 표현과 계산의 연결

- 수위는 현재 계산 제원의 최저와 최대 수위 사이 비율을 장면 JSON의 `reservoir.minY`~`maxY` 높이에 대응시킵니다. 화면의 모델 좌표가 실제 해발고를 그대로 뜻하지 않습니다.
- 발전 방류 합류 전에는 비발전 방류만 사용하고, 합류 후의 하류에는 전체 방류량을 연결합니다. 물길의 `kind`가 `turbine`이면 발전 방류, `release`이면 총방류, 그 밖의 물길은 비발전 방류 표현에 연결합니다.
- 수로 평균 유속과 수심은 Manning 식과 Q=A v로 근사합니다. 실제 폭, 경사, 거칠기 관측값으로 보정하지 않았으며 급경사 여수로의 가속, 도수, 게이트 유출은 풀지 않습니다.
- 호수에는 주변 지형의 평면 반사와 중력파 관계식에 따른 작은 물결을 표시합니다. 물보라는 중력에 따른 포물선 경로를 사용합니다. 자세한 가정과 표시 상한은 `날씨와_물_모형.md`에 있습니다.
- 날씨 선택은 구름, 안개, 비, 바람, 젖은 표면을 바꿉니다. 강우는 입력 유입량에 추가되지 않으며, 강우와 유출의 관계를 예측하는 기상 모형이 아닙니다. 화면 날씨는 메뉴 이동 중 유지되지만 프로젝트 JSON에 보관되는 기상 시계열은 아닙니다.
- 계산 모형의 `spillCms`는 발전을 거치지 않은 물의 양이며 실제 특정 여수로와 게이트의 유량 관측값이 아닙니다.
- 설정을 바꾼 뒤 다시 계산하기 전까지는 이전에 풀었던 조건의 결과를 표시합니다.

실제 방류 유속, 게이트별 분배, 하류 침수, 층별 탁수까지 연구하려면 별도의 수리 모형과 구조, 관측자료가 필요합니다.

## 이후 모델 교체

Blender에서 원본을 수정하고 GLB로 내보낸 뒤 `twin-dam.scene.json`의 좌표와 카메라도 함께 맞춥니다. glTF/Three.js의 Y축이 위쪽인 좌표계를 사용하므로 Blender의 기본 Z-up 좌표를 JSON에 그대로 복사하지 않습니다. 모델의 스케일, 방향, 수면 경계, 방류구 위치를 확인하고, 최소 수위와 최대 수위 및 무방류, 대유량 상태를 각각 확인하세요.

브라우저 새로고침은 저장하지 않은 작업을 초기화하므로 먼저 프로젝트 JSON을 저장합니다. 이 3D 교체는 물수지 방정식, 운영 정책, 입력자료 검증 코드를 수정하는 작업과 분리되어 있습니다.

## 1.3.1 물과 지형 사이의 틈 수정

- 호수 외곽을 최고 표시 수면보다 높은 산지 속까지 연장했습니다. 눈에 보이는 물가는 수면과 지형의 교차로 결정됩니다.
- 여수로 유입부 바닥과 벽, 댐 양끝을 닫힌 형상으로 연결했습니다. 빠진 첫 물길도 복원했습니다.
- 물과 벽이 맞닿도록 여수로 입구 시각 폭은 67m에서 61m로 좁아집니다. 수리 계산의 가정 폭은 61m를 유지합니다.
- 발전소 앞 수면은 세 출구를 받는 폭 100m에서 92m, 30m로 좁아집니다. 이 숫자는 표현용 가정이며 실제 설비 치수가 아닙니다.
- 합류부는 물 영역에 해당하는 둑 조각만 잘라, 큰 면 전체를 제거할 때 생기던 빈 공간을 줄였습니다.
- ‘여수로 입구’, ‘호숫가’ 버튼으로 연결부를 바로 확인할 수 있습니다.

표시 높이 116~121.5는 Blender 모형 내부의 상대 좌표입니다. 수치 수위의 최저~최고 비율을 이 범위에 대응시키며 범위 밖은 양끝으로 제한합니다. 실제 표고, 여유고, 수위 변화량은 3D 높이로 읽지 않습니다. 넓힌 물 면적을 저수량이나 유역 면적으로 사용하지 않습니다.

제작 환경: PyPI의 `bpy==5.1.2` 모듈(Python 3.13, Linux 컨테이너)에서 같은 스크립트를 실행했습니다. 수정 전 스크립트를 같은 환경에서 실행했을 때 1.3.1 배포 자산과 삼각형 수 843,548개, GLB 42,570,456바이트가 그대로 재현되었습니다. 1.4 결과는 메시 수가 늘고 삼각형 852,904개, GLB 43,359,824바이트입니다. 장면 JSON에는 `plaza` 카메라와 `detailPass` 항목이 추가되었고 수면 범위, 수로, 경계 계약은 바뀌지 않았습니다. 확인 범위는 `검증결과.md`의 1.4 항목에 있습니다.

## 1.5 정밀도 개선

## 1.6 AI 예상 수위면

1.6은 3D 장면에 AI 예상 수위면 하나를 더했습니다. 모델 기하와 장면 JSON은 1.5와 같습니다.

- 운영 실험실에서 AI 예측이 발행된 구간에 서면, 취수탑 앞 수면 위에 한 변 260 m의 반투명한 노란 표시면(`AI_Forecast_Level_Plane`)과 테두리 선(`AI_Forecast_Level_Edge`), 그리고 "AI 예상 수위 (h시간 뒤) 수위 m (현재 대비 차이)" 라벨이 나타납니다. 높이는 "예측 참고 지평"(기본 6시간) 뒤의 예상 수위를 수면과 같은 `reservoir.minY`~`maxY` 대응으로 바꾼 값에 표시용 여유 0.3을 더한 것입니다. 호수 전체가 아니라 표시면 한 장만 그리므로 수면 색은 바뀌지 않습니다. 수직 축이 압축된 표현이므로 표시면과 수면의 간격을 실제 수위 차이로 읽지 않습니다.
- 예상 수위는 AI 유입 예측값(1~24시간)을 현재 저수량에서 목표 저수량 유지 규칙으로 시뮬레이션한 값입니다. AI가 수위를 직접 예측하는 것이 아니라, 예측 유입량을 물수지 모형에 넣어 얻은 결과입니다. 제안 운영안이 고정 방류나 관측 재현이어도 예상 수위 계산은 목표 저수량 유지 규칙을 가정하므로, 목표 저수량 설정을 바꾸면 같은 유입 예측에서도 예상 수위가 달라집니다.
- 예측이 없는 구간(처음 48시간, 또는 AI 예측을 아직 만들지 않은 경우)에는 표시면과 라벨이 보이지 않고 읽기 상자에 "예측 없음"이 표시됩니다.
- 표시면은 `waterGroup`에 속하지만 물결 움직임이나 날씨 설정과 함께 켜지고 꺼지지 않으며, 수면 반사에도 참여하지 않습니다. `setForecast(levelM, {horizonHours, deltaM})` API로 높이와 라벨을 바꾸고, 운영 실험실이 구간마다 호출합니다. 라벨은 시설 라벨과 같은 겹침 회피 규칙을 따르며 ‘정보 패널’ 체크를 끄면 함께 숨겨집니다.
- 이 표시면은 표현용 보조선입니다. 실제 수위 예보, 홍수 경보, 운영 명령이 아닙니다.
