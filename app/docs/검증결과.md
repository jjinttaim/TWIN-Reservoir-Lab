## 아직 확인하지 않은 것

실제 기관 자료 전체, 실제 시설 재현 정확도, 실시간 수신, 제어, AI 학습, 층별 탁수, 하류 추적, 모든 브라우저/모바일 조합은 확인하지 않았습니다. 자동화 환경에서는 file:// 접근이 제한되어 로컬 HTTP 주소로 화면을 검증했습니다. 파일을 직접 여는 방식은 자동 UI 검증에 포함하지 않았습니다.
