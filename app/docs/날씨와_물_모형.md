# 날씨와 물 표현 (TWIN 1.3)

## 조작

맑음은 강우 0 mm/h, 바람 2.5 m/s, 비는 8 mm/h, 5 m/s, 장마는 45 mm/h, 11 m/s의 **화면 예제**입니다. 지역 기상 관측값이나 장마의 정의가 아닙니다. 강우와 바람 막대로 값을 조정할 수 있습니다. 구름, 먼 곳의 안개, 빗줄기 기울기, 표면의 젖은 정도, 물결이 달라집니다.

입력자료에 유입량이 이미 주어지므로 화면 강우를 물수지에 다시 더하지 않습니다. 실제 강우로 유입을 예측하려면 유역 면적, 침투, 유출 지연을 포함한 별도 강우–유출 모형과 검증자료가 필요합니다.

## 계산에서 따르는 관계

| 대상 | 반영한 관계 | 아직 가정인 것 |
| --- | --- | --- |
| 저수량 | 다음 저수량 = 이전 저수량 + (유입−방류)×시간 | 증발, 누수, 별도 취수의 독립 계산 제외 |
| 수로 수심과 평균 유속 | Q=(1/n) A R^(2/3) S^(1/2), v=Q/A | 직사각형 단면, 정상, 등류, 가정한 폭, 경사, 거칠기 |
| 호수 물결 | ω²=gk tanh(kh), k=2π/파장 | 평균 수심 45m, 작은 진폭, 바람–진폭 연결은 시각적 가정 |
| 물보라 | y=y₀+vᵧt−gt²/2 | 분사 위치, 초기 속도, 입자 수는 시각적 근사 |
| 비 | 중력과 항력으로 종단속도에 접근, 바람 방향 이동 | 강우량과 화면 입자 수의 연결은 연출 |

수로는 Q=0일 때 수심과 유속이 0입니다. 물의 무늬는 수로 중심선의 길이를 기준으로 근사 평균 유속에 연결해 이동합니다. 1.3에서는 중앙을 평균의 1.225배, 가장자리를 0.55배로 둔 평균 1의 포물선 분포를 시각 표현에만 적용합니다. 48m의 두 흐름 위상을 교차 전환해 무늬가 계속 늘어나는 현상을 줄입니다. 이 횡방향 분포는 실측 유속장이 아닙니다. 계산 수심은 자르지 않지만, 임의 지형을 뚫고 지나가지 않도록 **표시 깊이만 하류 3m, 방류수로 2.5m에서 제한**합니다. 이 상한은 저수량 계산으로 되돌아가지 않습니다.

급경사 여수로의 정상과 등류 가정이 실제로 성립한다고 검증하지 않았습니다. 게이트별 유량, 가속, 압력, 도수, 난류, 공기 혼입률, 침수 범위를 푸는 CFD 또는 부정류 수리해석을 대신하지 않습니다.

거칠기 계수는 하류 0.035, 발전수로 0.028, 콘크리트 여수로 0.016을 **예제 가정**으로 둡니다. 장면 JSON의 `roughnessN`, `energySlope`, `bedOffsetM`, 저수지의 `depthM`은 실제 자료를 확보한 뒤 근거와 함께 교체해야 합니다.

## 화면 표현

호수 반사는 주변 지형을 별도 카메라로 그린 평면 반사입니다. 물결에 따라 반사가 흔들리며 비는 작은 파문을 더합니다. 물속 지형 굴절, 퇴적물, 탁수 성층은 계산하지 않습니다. 호수 수면의 기준 높이는 기존 수위 표시 비율을 사용하므로 실제 해발고 또는 정밀 수심이 아닙니다.

돌, 콘크리트, 지형, 잎의 색, 요철, 거칠기 텍스처를 GLB에 넣었습니다. 구조와 나무는 소양강댐의 외형을 참고한 새 절차형 모델이며 실제 측량값이 아닙니다.

## 1.3 수로 연결

브라우저에서 하상, 측안, 약 100m 범위의 완만한 주변 지형을 생성합니다. 기존 Blender 파일과 GLB에는 이 추가 지형이 들어 있지 않습니다. 지형과 단면은 화면을 위한 가정이며 측량이나 토목 설계 결과가 아닙니다.

발전 방류 합류 전의 하류 구간은 비발전 방류만, 합류 후는 총방류를 사용합니다. 지류 말단은 하류 표시 수면 높이에 점진적으로 연결합니다. 이 연결부는 정상등류를 계산한 결과가 아니라 시각적 전이이며 실제 도수 위치나 홍수 도달 시간을 예측하지 않습니다. 비발전 방류가 0이면 여수로와 합류 전 흐름을 숨기며, 하류에는 정지한 기저 표면을 남길 수 있습니다.

## 1.3.1 경계 연결

3D 수면의 상대 높이 범위를 116~121.5로 조정했습니다. 입구 바닥 115와 댐마루 123 사이에서 물이 연결되도록 한 표현용 범위이며 수치 모형의 수위와 저수량은 변경하지 않습니다. 여수로의 첫 8.2m는 호수와 겹치는 영역의 높이를 같게 하고 36m 안에서 기존 표시 수심으로 전이합니다. 이 입구 구간은 일반 수로 표시 깊이 상한의 예외이며 실제 수문하부 유동 해석은 아닙니다. 발전소 앞 집수부와 입구 폭 변화도 시각 연결을 위한 형상입니다.

경계 검사는 파고 여유 0.45m를 포함합니다. 현재 파동식의 실제 정점 변위보다 여유 있게 설정한 형상 검사치이지 관측 파고가 아닙니다. 수문별과 발전기별 유량 배분, 배수 말단 경계조건, 실제 수위 변동에 따른 침수 면적은 해석하지 않습니다.
