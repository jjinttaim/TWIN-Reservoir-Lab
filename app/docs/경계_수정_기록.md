# 1.3.1 물과 구조물 경계 수정

확인일: 2026-10-12. 모든 입력은 가상 자료입니다.

사용자 첨부에서 보인 여수로 앞 빈틈은 고정 호수 polygon과 구조물의 경계 불일치였습니다. 게이트 앞에서 수면이 잘렸고, 첫 여수로 구간도 물 경로에서 빠져 있었습니다. 다른 호숫가와 발전소 측면 배출구의 연결 누락도 수정했습니다.

- Blender 5.1.2로 닫힌 접근수로, 측벽, 댐 접합부, 발전소 집수부를 포함한 자산을 생성했습니다. GLB 42,570,456바이트, 메시 305개, 삼각형 853,140개, 내장 이미지 12개입니다. 기존의 20MiB/50만 삼각형 초과 성능 주의는 남아 있습니다.
- 자동검사 69개 통과. 실제 GLB 정점, 삼각형, 변환행렬을 읽어 외곽 3면을 35m 간격으로 검사하고 댐 앞 접합 14점과 유입부 바닥 6점을 검사했습니다. 최고 표시 수면에 파고 여유를 더해도 경계가 땅속에 묻히고 최저 수면은 입구 바닥보다 높습니다.
- 입구의 물과 양옆 측벽이 겹치는지, 세 발전소 출구를 실제 물의 폭이 덮는지도 검사했습니다. 합류부에서는 물에 걸친 큰 둑 면 전체를 없애지 않고 마른 부분을 남깁니다.
- 검사 전용 가상 프로젝트를 앱에서 열어 수위 80m, 저수량 10백만m³, 무방류 조건과 수위 120m, 저수량 100백만m³, 총방류 300m³/s 조건을 확인했습니다. 상대 표시 높이는 각각 116과 121.5입니다. 두 입구 화면의 원본 PNG를 저장했습니다.
- 일반 예제의 발전만 방류와 총방류 300m³/s에서도 입구, 호숫가, 위쪽 카메라로 확인했습니다. 기존 공중 절단면이 지형에 이어지고 물길이 게이트 뒤로 연결됩니다.
- Mac Claude의 같은 Waterprize 대화에서 후속 비판 검토를 받았습니다. 실제 자산 제작, 회귀검사, 화면 검사는 Codex가 수행했습니다.

검사 자료는 work의 전용 가상 프로젝트이며 배포 기본 예제와 다릅니다. 3D 높이 범위와 연결부 보간은 외형 표현용이며 실제 수위, 저수량, 유량 계산은 바꾸지 않았습니다. 실측 지형이나 CFD 검증, 장면 전체의 완전한 위상 증명을 뜻하지 않습니다.
