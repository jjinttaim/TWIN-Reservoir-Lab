# TWIN Reservoir Lab 데스크톱 앱 설치 안내 (1.6.1)

브라우저와 로컬 서버 없이 실행하는 Mac 앱입니다. 웹 앱과 같은 화면과 계산을 사용하며, 앱 안의 `twin://` 사설 주소로 파일을 읽으므로 인터넷 연결이나 Python이 필요 없습니다. 모든 자료는 이 컴퓨터 안에서만 처리됩니다.

## 배포용 묶음

다른 사람에게 나눠 줄 묶음은 상위 폴더의 `TWIN_Reservoir_Lab_1.6.1_배포/`에 있습니다. `읽어주세요.txt`(어느 파일을 받을지, 보안 경고 처리, SHA-256), `Mac/`(zip과 설치안내_Mac.txt), `Windows/`(zip과 설치안내_Windows.txt), `SHA256SUMS.txt`로 구성됩니다. 이 폴더를 통째로 압축하거나 클라우드 드라이브, GitHub Releases 등에 올려 공유하면 됩니다. 두 묶음 모두 유료 개발자 인증서 서명과 공증은 하지 않았으므로 첫 실행 때 보안 경고가 한 번 나오며, 그 처리 방법이 각 설치 안내에 적혀 있습니다.

## 설치 (받은 앱 묶음을 쓰는 경우)

1. `TWIN_Reservoir_Lab_1.6.1_mac_arm64.zip`을 풀면 `TWIN Reservoir Lab.app`과 `설치.command`가 나옵니다.
2. `설치.command`를 더블클릭합니다. 앱에 로컬 서명을 넣고 `~/Applications`에 복사한 뒤 실행합니다. Terminal 창이 열렸다가 닫히면 끝입니다.
3. 이후에는 Launchpad나 `~/Applications` 폴더에서 `TWIN Reservoir Lab`을 엽니다.

`설치.command` 대신 손으로 하려면 Terminal에서 다음을 실행합니다.

```
xattr -dr com.apple.quarantine "TWIN Reservoir Lab.app"
codesign --force --deep --sign - "TWIN Reservoir Lab.app"
cp -R "TWIN Reservoir Lab.app" ~/Applications/
open ~/Applications/"TWIN Reservoir Lab.app"
```

이 앱은 Apple 개발자 인증서로 서명하지 않은 연구용 시제품입니다. 인터넷에서 내려받은 경우 macOS가 처음 실행을 막을 수 있으며, 그때는 Finder에서 앱을 오른쪽 클릭한 뒤 ‘열기’를 선택하거나 시스템 설정의 ‘개인정보 보호 및 보안’에서 ‘그래도 열기’를 누릅니다. Apple Silicon(M1 이후) Mac용 묶음입니다. Intel Mac에서는 아래 방법으로 `npm run pack:mac-intel`을 실행해 직접 만듭니다.

## Windows 버전

`TWIN_Reservoir_Lab_1.6.1_win_x64.zip`을 풀면 `TWIN Reservoir Lab` 폴더가 나옵니다. 폴더 안의 `TWIN Reservoir Lab.exe`를 실행합니다(폴더째 두어야 합니다). 서명이 없어 처음 실행 때 SmartScreen 창이 뜨면 ‘추가 정보’ 뒤 ‘실행’을 누릅니다. 자세한 내용은 묶음 안의 `설치안내_Windows.txt`에 있습니다. 64비트 Windows 10 이상용이며, Mac 앱과 같은 소스와 화면입니다.

Windows 묶음은 `npm run pack:win`으로 만듭니다. Linux나 Mac에서도 Wine 없이 만들 수 있도록, 아이콘과 버전 정보는 `win-resources.mjs`(resedit)로 exe에 직접 써 넣습니다.

## 직접 만들기 (개발용)

Node.js 20 이상이 필요합니다. 처음 한 번 Electron(약 100 MB)을 내려받습니다.

```
cd desktop
npm install
npm run start          # 포장 없이 바로 실행 (stage 폴더를 만든 뒤 Electron으로 엽니다)
npm run pack:mac       # out/TWIN Reservoir Lab-darwin-arm64/ 에 .app 생성
npm run pack:win       # out/TWIN Reservoir Lab-win32-x64/ 에 Windows 64비트 폴더 생성
npm run dist:mac       # Mac에서 DMG와 zip 생성 (electron-builder, out/dist/)
```

`npm run stage`는 상위 폴더의 `index.html`, `assets`, `사용안내.md`를 `stage/app/`으로 복사합니다. 웹 앱을 고친 뒤에는 상위 폴더에서 `npm run build`로 `assets/app.js`를 다시 번들한 다음 여기서 다시 포장합니다. `stage/`와 `out/`은 생성물이므로 보관할 필요가 없습니다.

## 구조

- `main.cjs`: Electron 주 프로세스. `twin://app/` 스킴에 앱 폴더를 연결하고 창, 한국어 메뉴, 정보 창을 만듭니다. 렌더러는 샌드박스와 컨텍스트 격리를 켠 상태이며 Node 기능을 노출하지 않습니다.
- `stage.mjs`: 포장용 스테이지 폴더 생성.
- `builder.yml`: electron-builder 설정 (DMG).
- `icon.icns`, `icon.ico`, `icon.png`: 앱 아이콘 (팀 TWIN 로고 심벌).
- `win-resources.mjs`: Windows exe에 아이콘과 버전 정보를 써 넣는 스크립트.
- `설치안내_Windows.txt`: Windows 묶음에 넣는 안내.

## 문제 해결

- 앱이 바로 종료되거나 "손상되었다"는 메시지가 나오면 위의 `codesign --force --deep --sign -` 명령을 다시 실행합니다. 앱을 다른 위치로 옮긴 뒤에도 서명은 유지됩니다.
- 3D 장면이 비어 있으면 메뉴 ‘보기 > 개발자 도구’의 콘솔에서 오류를 확인합니다. 앱 묶음 안의 `Contents/Resources/app/app/assets/models/twin-dam.glb`가 약 40 MB인지 확인합니다.
- 프로젝트 JSON 저장과 CSV 내보내기는 macOS 저장 대화상자로 진행됩니다. 파일 열기는 웹 앱과 같은 파일 선택 창을 사용합니다.
